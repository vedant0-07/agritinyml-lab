About the Project

Problem Statement

Cloud-based agricultural AI systems introduce internet dependency, communication overhead, and latency. In remote or resource-constrained agricultural settings, reliable cloud connectivity cannot be assumed.

Proposed Solution

Utilize TinyML and FPGA-based edge acceleration to perform agricultural AI inference locally — on-device, in real-time, without cloud dependency. INT8 quantization reduces model size and improves hardware suitability.

PROJECT OBJECTIVES
01 Develop an FPGA-based TinyML edge accelerator for agricultural AI applications.
02 Enable real-time local inference with reduced dependency on cloud connectivity.
03 Support multiple agricultural AI workloads through an adaptive/reconfigurable architecture.
04 Reduce computational and memory requirements through TinyML and INT8 quantization.
05 Evaluate the performance of software inference and eventually FPGA-based acceleration.
06 Develop a scalable platform for agriculture applications such as irrigation prediction, disease detection, pest identification and soil monitoring.
